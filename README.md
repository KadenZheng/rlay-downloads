# Rlay for Mac

Switch supported Claude Code, Codex and OpenCode sessions. See which session needs you and answer Rlay plugin questions in one Mac inbox. Built-in approvals stay with the assistant.

**[Try the free Mac preview](https://tryrlay.com/download)** · [Interactive demo](https://tryrlay.com/#demo) · [Compatibility](https://tryrlay.com/compatibility)

No signup, payment card or Rlay license is needed for the preview. Use your own AI accounts and available allowance.

## Install and try your first question

1. Download Rlay 0.3.11 and extract the ZIP on your Apple Silicon Mac. Open **Install Relay.command**, then open **Rlay**. The installer keeps the legacy Relay filename; Rlay is the app name.
2. In Setup, choose **In my terminal** and copy your assistant command into a disposable Git project's terminal. Select your existing provider/model for OpenCode.
3. Ask: “Ask me through Rlay whether this demo button should say Continue or Next. Do not edit any files.” Answer in the Inbox and check that the same session receives the choice. This uses your provider's allowance.
4. For a terminal session started through Rlay, press **Ctrl ]** to switch supported assistants or local account profiles. Keep the original session and archive until you verify the result.

To connect an existing assistant, use **Setup → In my existing assistant → Connect**, then follow its reload/restart instructions. [First-question and notification troubleshooting](https://tryrlay.com/guides/agent-waiting-for-input).

## Tested setup and limits

Rlay **0.3.11**, Apple Silicon, **macOS 26.6.2**. Tested CLI versions: Claude Code **2.1.294 / 2.1.304**, Codex **0.162.1 / 0.163.0**, OpenCode **1.18.18 / 1.19.0**. Check the [current compatibility and import limits](https://tryrlay.com/compatibility) before installing. Other versions are not claimed compatible.

Transfers and session observation make no model calls. Continuing sends context to your selected provider under your account. Rlay does not bypass quotas, transfer permissions or include AI usage. OpenCode cloud-model continuation remains outside the verified scope. Arbitrary Claude Desktop account switching and automatic Codex Desktop indexing are unsupported. The direct Mac offer excludes public phone/App Store apps.
